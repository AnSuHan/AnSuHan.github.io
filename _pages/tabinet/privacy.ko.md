## 1. 한눈에

태비넷은 개인정보를 수집하거나 외부로 전송하지 않습니다. 저장되는 모든 내용은 사용자의 브라우저 안에
남습니다. 태비넷 서버는 없으며, 통계 도구나 광고도 사용하지 않습니다.

## 2. 저장되는 것

- **저장한 탭 그룹** — 사용자가 저장하기로 선택한 탭의 제목과 주소, 그리고 그룹 이름·색
- **설정 값** — 워크스페이스를 백그라운드에 살려 둘지, 탭을 미리 불러올지 등

이 데이터는 크롬 확장 저장소에 기록되며 기본적으로 사용자 컴퓨터에만 저장됩니다. *기기 간 동기화*를 켜면
크롬이 사용자의 구글 계정에 저장해 로그인한 다른 크롬에서도 보입니다. 이 경우 데이터는 사용자 계정 아래에서
구글이 처리하며, 개발자는 접근할 수 없습니다.

## 3. 권한이 필요한 이유

| 권한 | 사용 목적 |
|---|---|
| `tabs` | 워크스페이스를 저장·복원하기 위해 탭의 제목과 주소를 읽습니다. |
| `tabGroups` | 워크스페이스를 크롬 탭 그룹으로 만들고 갱신합니다. |
| `storage` | 저장한 워크스페이스와 설정을 브라우저에 보관합니다. |
| `downloads` | 사용자가 내보내기를 실행할 때 JSON 파일을 저장합니다. |
| `sidePanel` | 사이드바 화면을 표시합니다. |
| 호스트 접근 (`http`/`https`) | 워크스페이스를 열 때 저장해 둔 페이지를 미리 불러와, 탭을 클릭하는 순간 바로 보이게 합니다. 요청은 사용자의 브라우저에서 해당 사이트로 직접 나가며, 개발자에게 전송되는 내용은 없습니다. |

## 4. 하지 않는 것

- 개발자나 제3자에게 데이터를 전송하지 않습니다.
- 추적·통계·광고·프로파일링을 하지 않습니다.
- 방문 기록을 읽지 않으며, 사용자가 저장한 탭만 보관합니다.
- 데이터를 판매하거나 공유하지 않습니다.

## 5. 처리 위탁과 국외 이전

개발자에게 전송되는 데이터가 없으므로, 개발자가 처리를 위탁하거나 국외로 이전하는 개인정보는 없습니다.
사용자가 *기기 간 동기화*를 켠 경우에 한해 크롬이 사용자의 구글 계정에 데이터를 저장하며, 이는 사용자와
구글 사이의 처리로 구글의 정책을 따릅니다.

## 6. 보유 기간과 파기

- 저장한 워크스페이스는 사용자가 삭제하거나 확장을 제거할 때까지 브라우저에 유지됩니다.
- 확장을 삭제하면 로컬에 저장된 데이터가 함께 지워집니다.
- 동기화를 사용했다면 구글 계정에 있는 사본은 크롬 동기화 설정에서 삭제할 수 있습니다.
- 개발자가 보관하는 사본은 존재하지 않습니다.

## 7. 아동

태비넷은 일반 사용자용 도구이며 만 13세 미만 아동을 대상으로 하지 않습니다.
