열려 있는 탭을 **이름과 색이 있는 그룹으로 저장**하고, 필요할 때 그 묶음으로 되돌아가는 Chrome 확장입니다.
사이드바에서 저장·전환하고, 저장한 워크스페이스를 열면 탭이 미리 로딩돼 클릭하는 순간 바로 보입니다.

## 주요 기능

- 현재 창 또는 탭 그룹을 통째로 저장
- 워크스페이스 전환 — 이전 묶음은 접히고, 돌아오면 그대로
- JSON 으로 내보내기·불러오기
- 기기 간 동기화(선택) — 크롬 계정 동기화 사용
